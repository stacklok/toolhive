## thv secret upgrade-protection

Upgrade encrypted secrets protection

### Synopsis

Upgrade a legacy encrypted secrets file to the current Argon2id protection.

This operation is irreversible for older ToolHive versions: they cannot read the
upgraded file. Stop or upgrade all local ToolHive processes before continuing.

```
thv secret upgrade-protection [flags]
```
